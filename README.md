# Atm_Simulator_
ATM Simulation System
A command-line (terminal-based) ATM simulation written in pure Python, built
as a college course project. It demonstrates core programming concepts —
functions, conditionals, loops, exception handling, and file handling —
through a realistic, menu-driven banking workflow.
Disclaimer: This is an educational simulation only. It does not
connect to any real bank, does not move real money, and should never
be used to manage actual financial accounts. It is intended purely to
demonstrate programming concepts for a course project.
